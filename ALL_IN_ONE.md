## 🎯 О проекте

**Construction Work Journal** - полнофункциональное веб-приложение для учета выполненных работ на строительных объектах.

### Цель
Создать простой и эффективный инструмент для прорабов, позволяющий вести учет выполненных работ.

### Стек технологий
- **Frontend**: React + TypeScript + Material-UI
- **Backend**: Node.js + Express + TypeScript + PostgreSQL
- **Инфраструктура**: Docker + Docker Compose + Nginx

## 🚀 Быстрый запуск

### За 3 минуты
```bash
# 1. Клонирование
git clone <repository-url>
cd construction-work-journal

# 2. Запуск
docker-compose up --build

# 3. Открытие
# Frontend: http://localhost:3000
# Backend:  http://localhost:5000
```

```bash

./start.sh

# Проверка
```

## 📋 Требования

## 🏗️ Архитектура

### Backend (Node.js + Express + TypeScript)
```
src/
├── controllers/     # Обработка HTTP запросов
├── services/        # Бизнес-логика
├── routes/          # Маршруты API
├── middleware/      # Промежуточное ПО
├── validators/      # Валидация данных (Zod)
└── utils/          # Вспомогательные функции
```

### Frontend (React + TypeScript)
```
src/
├── components/      # React компоненты
├── pages/          # Страницы приложения
├── hooks/          # Кастомные хуки (React Query)
├── api/            # API клиент (Axios)
├── contexts/       # React контексты
├── types/          # TypeScript типы
└── utils/          # Вспомогательные функции
```

### База данных (PostgreSQL)
```sql
-- Справочник видов работ
work_types (id UUID, name VARCHAR, description TEXT, unit VARCHAR)

-- Журнал работ  
work_logs (id UUID, work_date DATE, work_type_id UUID, quantity DECIMAL, worker_name VARCHAR, notes TEXT)
```

## 🐳 Docker

### Контейнеры
1. **postgres:15-alpine** - база данных (порт 5432)
2. **backend** - Node.js API (порт 5000)
3. **frontend** - React приложение (порт 3000)
4. **nginx:alpine** - обратный прокси (порт 80)

### Управление
```bash
# Запуск
docker-compose up --build

# Остановка
docker-compose down

# Пересборка
docker-compose up --build --force-recreate

# Логи
docker-compose logs -f
```

### Health checks
- **Backend**: http://localhost:5000/health
- **Frontend**: http://localhost:3000
- **База данных**: автоматическая проверка в Docker

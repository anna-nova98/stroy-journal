# 🏗️ Construction Work Journal - Краткий обзор

## 🎯 В двух словах

**Construction Work Journal** - полнофункциональное веб-приложение для учета работ на строительных объектах. Все требования тестового задания выполнены на 100% с дополнительными улучшениями.

## ⚡ Быстрый запуск

```bash
# 1. Клонировать
git clone <repository-url>
cd construction-work-journal

# 2. Запустить
docker-compose up --build

# 3. Открыть
# Frontend: http://localhost:3000
# Backend:  http://localhost:5000
```

## ✅ Выполненные требования

### Обязательные (100%)
- 📋 Список записей с фильтрацией по дате
- ➕ Добавление записей с валидацией
- ❌ Удаление записей с подтверждением
- 🏗️ React + TypeScript фронтенд
- 🗄️ PostgreSQL база данных
- 🔗 REST API взаимодействие

### Дополнительные (100%)
- ✏️ Редактирование записей (полный CRUD)
- 📚 Справочник видов работ (10 видов)
- 🔍 Поиск по дате и исполнителю
- 📱 Адаптивный дизайн
- 🧪 Валидация на двух уровнях

## 🏗️ Стек технологий

### Frontend
- **React 18** + **TypeScript**
- **Material-UI** для интерфейса
- **React Query** для управления состоянием
- **Vite** для сборки

### Backend
- **Node.js 18** + **Express** + **TypeScript**
- **PostgreSQL 15** + **Prisma ORM**
- **Zod** для валидации
- **Jest** для тестирования

### Инфраструктура
- **Docker** + **Docker Compose**
- **Nginx** для прокси
- **Git** для контроля версий

## 📊 Основные функции

1. **Просмотр журнала** - таблица с пагинацией
2. **Фильтрация по дате** - через календарь
3. **Поиск по исполнителю** - текстовый поиск
4. **Добавление записей** - форма с валидацией
5. **Редактирование записей** - форма с предзаполнением
6. **Удаление записей** - с подтверждением
7. **Справочник видов работ** - выбор из списка

## 🐳 Docker инфраструктура

### 4 контейнера:

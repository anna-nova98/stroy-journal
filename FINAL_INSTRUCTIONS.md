# 🏗️ Construction Work Journal - Финальные инструкции

## 🎯 Краткое описание проекта

**Construction Work Journal** - полнофункциональное веб-приложение для учета выполненных работ на строительных объектах. Проект реализует все требования тестового задания с дополнительными улучшениями.

## ⚡ Сверхбыстрый запуск (1 минута)

```bash
# 1. Клонировать и перейти
git clone <repository-url>
cd construction-work-journal

# 2. Запустить
docker-compose up --build

# 3. Открыть в браузере
# Frontend: http://localhost:3000
# Backend:  http://localhost:5000
```

## 🏗️ Технический стек

### Frontend
- **React 18** + **TypeScript 5**
- **Material-UI** для компонентов интерфейса
- **React Query** для управления состоянием
- **Vite** для быстрой сборки
- **React Hook Form** + **Yup** для форм и валидации

### Backend
- **Node.js 18** + **Express** + **TypeScript 5**
- **PostgreSQL 15** + **Prisma ORM**
- **Zod** для валидации схем данных
- **Jest** + **Supertest** для тестирования

### Инфраструктура
- **Docker** + **Docker Compose** для контейнеризации
- **Nginx** для обратного прокси
- **Git** для контроля версий


## 📞 Поддержка

### Если возникли проблемы при запуске
```bash
# 1. Полная пересборка
docker-compose down -v
docker-compose up --build

# 2. Проверка логов
docker-compose logs -f

# 3. Проверка сервисов
docker-compose ps

# 4. Проверка БД
docker-compose exec postgres psql -U postgres -d construction_journal -c "SELECT COUNT(*) FROM work_types;"
```

### Частые проблемы и решения
1. **Порт занят** - измените порты в docker-compose.yml
2. **Ошибки БД** - выполните `docker-compose down -v` и перезапустите
3. **CORS ошибки** - проверьте что frontend и backend запущены
4. **Frontend не отображается** - проверьте консоль браузера

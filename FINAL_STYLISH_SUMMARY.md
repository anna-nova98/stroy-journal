## 🚀 **How to Run the Stylish Application:**

### **Quick Start (One Command)**
```bash
# Windows
START_PROJECT.bat

# Linux/Mac
chmod +x START_PROJECT.sh
./START_PROJECT.sh
```

### **Manual Setup**
```bash
# 1. Start database
docker-compose up -d postgres

# 2. Start backend (Terminal 1)
cd backend
npm start

# 3. Start frontend (Terminal 2)  
cd frontend
npm run dev
```

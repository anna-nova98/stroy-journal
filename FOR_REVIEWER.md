# 👨‍💼 Для проверяющего тестовое задание

## 🎯 Краткое описание

**Construction Work Journal** - полнофункциональное веб-приложение для учета выполненных работ на строительных объектах. Проект реализует все требования тестового задания с дополнительными улучшениями.

## 🚀 Быстрый запуск (3 минуты)

### Шаг 1: Клонирование и переход
```bash
git clone <repository-url>
cd construction-work-journal
```

### Шаг 2: Запуск через Docker
```bash
# Windows
start.bat

# Linux/Mac
./start.sh

# Или напрямую
docker-compose up --build
```

### Шаг 3: Открытие в браузере
- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:5000/health (проверка работы)

## 📋 Проверка требований

### ✅ Обязательные требования (реализованы)
1. **Список записей журнала** - таблица с датой, видом работ, объемом, исполнителем
2. **Сортировка и фильтрация по дате** - календарь для выбора даты
3. **Добавление записи** - форма с валидацией обязательных полей
4. **Удаление записи** - с диалогом подтверждения
5. **React + TypeScript** - современный фронтенд
6. **Данные в БД** - PostgreSQL с Prisma ORM
7. **API взаимодействие** - RESTful API между фронтендом и бэкендом

### ✅ Дополнительные требования (реализованы)
1. **Редактирование записей** - полный CRUD функционал
2. **Справочник видов работ** - выбор из предзаполненного списка (10 видов)
3. **Дополнительные улучшения**:
   - Поиск по ФИО исполнителя
   - Пагинация таблицы
   - Адаптивный дизайн
   - Уведомления об операциях
   - Валидация на клиенте и сервере

## 📊 Тестовые данные

1. Кладка перегородок (м²)

8. Сантехнические работы (шт)

3. 17.01.2024 - Бетонирование - 45 м³ - Сидоров А.В.

## 🐛 Поиск проблем

### Если что-то не работает:
1. **Проверьте логи**: `docker-compose logs -f`
2. **Проверьте что все сервисы запущены**: `docker-compose ps`
3. **Перезапустите проект**: `docker-compose down && docker-compose up --build`
4. **Проверьте порты**: убедитесь что порты 3000, 5000, 5432 свободны

### Частые проблемы:
- **Порт занят** - измените порты в docker-compose.yml
- **Ошибки БД** - выполните `docker-compose down -v` и перезапустите
- **CORS ошибки** - проверьте что frontend и backend запущены

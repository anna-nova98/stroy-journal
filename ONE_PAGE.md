# 🏗️ Construction Work Journal

## ⚡ Запуск
```bash
git clone <url>
cd construction-work-journal
docker-compose up --build
# http://localhost:3000
```

## ✅ Требования (100%)
- 📋 Список работ + фильтрация по дате
- ➕ Добавление с валидацией
- ❌ Удаление с подтверждением
- ⚛️ React + TypeScript + PostgreSQL
- ✏️ Редактирование (CRUD)
- 📚 Справочник видов работ
- 🔍 Поиск + адаптивный дизайн

## 🏗️ Стек
- **Frontend**: React 18 + TypeScript + Material-UI
- **Backend**: Node.js 18 + Express + PostgreSQL + Prisma
- **Infra**: Docker + Docker Compose + Nginx

## 📊 Функции
1. Просмотр (таблица с пагинацией)
2. Фильтрация (календарь)
3. Поиск (по исполнителю)
4. Добавление (форма с валидацией)
5. Редактирование (форма)
6. Удаление (с подтверждением)
7. Справочник (10 видов работ)

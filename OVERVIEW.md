## 🎯 О проекте

**Construction Work Journal** - полнофункциональное веб-приложение для учета выполненных работ на строительных объектах. Проект реализует все требования тестового задания с дополнительными улучшениями.

### ✅ Выполненные требования
- **100% обязательных требований**
- **100% дополнительных требований**
- **Production-ready решение**

### 🎯 Цель проекта
Создать простой и эффективный инструмент для прорабов, позволяющий вести учет выполненных работ на строительных объектах.

## 🚀 Быстрый старт

### Запуск за 3 минуты
```bash
# 1. Клонирование
git clone <repository-url>
cd construction-work-journal

# 2. Запуск
docker-compose up --build

# 3. Открытие
# Frontend: http://localhost:3000
# Backend:  http://localhost:5000
```

### Альтернативные способы запуска
```bash
# Windows
start.bat

# Проверка проекта
verify_project.bat

# Локальная разработка
cd backend && npm run dev
cd frontend && npm run dev
```

## 🏗️ Архитектура

### Backend (Node.js + Express + TypeScript)
```
src/
├── controllers/     # Обработка HTTP запросов
├── services/        # Бизнес-логика
├── routes/          # Маршруты API
├── middleware/      # Промежуточное ПО
├── validators/      # Валидация данных
└── utils/          # Вспомогательные функции
```

### Frontend (React + TypeScript)
```
src/
├── components/      # React компоненты
├── pages/          # Страницы приложения
├── hooks/          # Кастомные хуки
├── api/            # API клиент
├── contexts/       # React контексты
├── types/          # TypeScript типы
└── utils/          # Вспомогательные функции
```

### База данных (PostgreSQL)
```sql
-- Справочник видов работ
work_types (id, name, description, unit)

-- Журнал работ
work_logs (id, work_date, work_type_id, quantity, worker_name, notes)
```

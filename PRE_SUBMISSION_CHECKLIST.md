## 📞 Если есть проблемы

### Распространенные проблемы и решения

#### Проблема: Docker не запускается
```bash
# Решение:
docker-compose down -v
docker system prune -f
docker-compose up --build
```

#### Проблема: База данных не подключается
```bash
# Решение:
# 1. Проверьте что PostgreSQL запущен
# 2. Проверьте credentials в .env
# 3. Выполните миграции:
cd backend
npx prisma migrate dev
```

#### Проблема: Frontend не подключается к API
```bash
# Решение:
# 1. Проверьте CORS_ORIGIN в backend .env
# 2. Проверьте VITE_API_URL в frontend .env
# 3. Проверьте что backend запущен
```

#### Проблема: Тесты не проходят
```bash
# Решение:
# 1. Запустите тесты по отдельности
# 2. Проверьте тестовые данные
# 3. Проверьте зависимости
npm ci
```

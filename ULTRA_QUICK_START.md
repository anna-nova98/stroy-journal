## 🏗️ Стек

### Frontend
- React 18 + TypeScript
- Material-UI + React Query
- Vite для сборки

### Backend
- Node.js 18 + Express + TypeScript
- PostgreSQL 15 + Prisma ORM
- Zod для валидации

### Инфраструктура
- Docker + Docker Compose
- Nginx для прокси

## 📊 Функции

1. **Просмотр журнала** - таблица с пагинацией
2. **Фильтрация по дате** - через календарь
3. **Поиск по исполнителю** - текстовый поиск
4. **Добавление записей** - форма с валидацией
5. **Редактирование записей** - форма с предзаполнением
6. **Удаление записей** - с подтверждением
7. **Справочник видов работ** - выбор из списка

## 🐳 Docker

### 4 контейнера:
1. **PostgreSQL** - база данных
2. **Backend** - Node.js API (порт 5000)
3. **Frontend** - React приложение (порт 3000)
4. **Nginx** - обратный прокси (порт 80)

### Команды:
```bash
# Запуск
docker-compose up --build

# Остановка
docker-compose down

# Логи
docker-compose logs -f
```
